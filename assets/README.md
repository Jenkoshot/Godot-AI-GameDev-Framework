# Asset Repository

A shared, git-tracked library of game-agnostic raw assets (3D models, textures, audio) pulled out of past projects. 

## Master Index

*The following is a high-level overview of the available assets so agents can decide whether to reuse, adapt, or build from scratch.*

### Categories
- **`building_pieces/`**: Modular walls, floors, roofs, and architectural structures.
- **`characters/`**: Player characters, NPCs, and enemies.
- **`environment_assets/`**: Trees, rocks, terrain meshes, and foliage.
- **`props/`**: Interactive objects, clutter, furniture, and items.
